# RopeRunner – Rope-Climbing Search-and-Rescue Robot

<img width="750" height="860" alt="IMG_3243" src="https://github.com/user-attachments/assets/d2367531-42ff-43a4-ba50-38ef6cb610b1" />


RopeRunner is a rope-climbing robot developed to support search-and-rescue operations in dangerous or hard-to-reach environments.

The project explores how robotics and embedded systems can be used to improve access to challenging locations while reducing the risks faced by human rescuers.



## Project Overview

RopeRunner was developed as a search-and-rescue robotics project focused on navigating suspended ropes in environments that may be difficult or dangerous for humans to access.

The robot uses a motor-driven mechanism to move along a rope, with an ESP32 microcontroller handling its control system. The project involved mechanical design, embedded programming, motor control, and testing.


## Technologies & Components

- Microcontroller: ESP32
- Motor Control: L298N motor driver
- Programming: C++ (Arduino framework)
- Communication: Bluetooth
- Mechanical Design: SolidWorks
- Sensors: Rotary encoder and voltage sensor
- Power: 2-cell (7.4V) battery system
  

## Key Features

- Rope-climbing movement for navigating suspended ropes.
- Bluetooth-based control for forward, backward, stop, and speed adjustment.
- ESP32-based motor control system.
- Rotary encoder for tracking movement and estimating distance travelled.
- Battery voltage monitoring.
- Telemetry system for monitoring robot performance.
